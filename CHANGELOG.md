## [0.1.0] - 2026-07-29

### Added

- Background-only Zen Space and tab discovery through the privileged extension
  and shared local daemon.
- Semantic page interaction, bounded screenshots, explicit picker-free uploads,
  bounded resource downloads, media inspection, and on-device transcription.
- MCP browser automation, setup and diagnostic CLI commands, conservative tab
  cleanup, and structured recovery errors.
- Portable safety checks and headed non-interference acceptance tests.
